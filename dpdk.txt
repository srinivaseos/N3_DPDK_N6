In DPDK, struct rte_eth_stats is defined in rte_ethdev.h and is used to hold statistics for an Ethernet port. It looks roughly like this (simplified for clarity):

struct rte_eth_stats {
    uint64_t ipackets;    /**< Total number of successfully received packets. */
    uint64_t opackets;    /**< Total number of successfully transmitted packets. */
    uint64_t ibytes;      /**< Total number of successfully received bytes. */
    uint64_t obytes;      /**< Total number of successfully transmitted bytes. */
    uint64_t imissed;     /**< Number of missed packets (RX queue full). */
    uint64_t ierrors;     /**< Number of erroneous packets received. */
    uint64_t oerrors;     /**< Number of failed packets transmitted. */
    uint64_t rx_nombuf;   /**< Number of RX mbufs not available. */
};

When receiving packets (RX): The PMD (driver) configures these fields automatically. You only read them to know how big the packet is.
When modifying headers (Prepend): If you push a new header onto the front via rte_pktmbuf_prepend(m, 14), DPDK automatically increments both data_len and pkt_len by 14.
When stripping headers (Adj): If you strip an outer header via rte_pktmbuf_adj(m, 14), DPDK automatically decrements both data_len and pkt_len by 14.
